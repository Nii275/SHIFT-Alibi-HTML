SHIFT / 改口 — HTML 网页版 0.6 游玩指导

一、三个入口
本仓库包含 web 网页源码、scripts 启动辅助、tests 自动测试和 docs 文档。
双击「Play.cmd」即可打开浏览器游戏，无需 C++、编译器或安装 Node。
有 Python 3.9+ 时会后台启动本地服务并打开浏览器；没有 Python 则直接打开 HTML，离线玩法完整可用。
也可以直接双击「web/index.html」游玩。请整体保留本文件夹，不要只复制一个 HTML 而丢掉图片、字体和脚本。
如果下载的是 ZIP，请先完整解压。推荐 Chrome 或 Edge。

二、先体验单人教学
在菜单点击「单人教学」。你扮演侦探，体验读剧本、取证、三轮审问和三选一。
教学可以快进到共同回答截止时间，不计分。熟悉后选择「开始双人对战」。

三、正式双人流程
1. 同机交接。按屏幕提示交给当前玩家；私密阶段另一人请回避。
2. 罪犯读剧本。旁白与人物逐幕讲述，点击下一幕；文字未显示完时先补全台词。可上一幕、全文、直接显示台词或跳到末幕。阅读不限时。
3. 60 秒改稿。时间线、物品、行动、目击证词，总共净修改一到两处。选回原文可释放修改额度，不能改别人剧本和物证。锁定后交给侦探。
4. 侦探读公开案情。了解背景和三个人，不含私密作案经过。
5. 分类调查。180 秒、4 点额度。点人物查看档案，点取证来源获得记录；完整档案 3 点，时间记录/交接物证各 1 点，走廊片段 2 点。已取得记录可重复阅读，不再扣额度。调查时查案卷仍计时。
6. 提出问题。每案三轮，每轮同一个问题问三人。可自拟中文问题，或使用参考题、填入后改写；可收起参考。选择希望核对的资料范围，题目原文会保留在案卷。上限 600 字节，约 200 个汉字。
7. 罪犯回答。选择内容和语气，再提交锁定。三人共享 30 秒期限，提前锁定不提前公布；期间可查剧本，侦探调查计时冻结。没有提交则使用一致的默认答复。
8. 同时复盘。共同截止后，三份回答一起公布。对照人物口供、此前答复和证据，别把紧张或强硬直接当成犯罪。
9. 最终指认。完成三轮，选中一名嫌疑人，再点击「三选一 / 最终指认」确认。只有一次机会。

四、得分与轮换
指认正确：侦探得 1 分。错误或调查超时：罪犯得 1 分。
两案一组，双方各当一次侦探和罪犯后判断胜负。首组 1:1 加赛两案，四案仍平分则平局。
三名嫌疑人中一人由真人罪犯控制，另外两人为人机。公开界面不标控制方式。

五、DeepSeek 人机，可选
没有 Key 也能离线玩完整流程。
菜单或页顶打开「AI / 演出设置」，填入自己的 API Key，启用在线表达并测试连接、保存。
模型为 deepseek-flash。罪犯锁定后，两个人机参考实际回答的句长、语气和紧张感生成表达，各自事实仍由剧本决定。
每轮最多两次请求，费用来自你的 DeepSeek 账户。失败、取消、超时或不合适的输出会回退本地台词，不拖延共同截止。
直接双击 HTML 时，浏览器可能限制跨域调用。推荐通过一键启动打开本地服务；本地服务需要 Python 3.9+，仅监听本机 127.0.0.1 并固定转发官方 DeepSeek。
网页版 Key 仅保留在当前页面内存，刷新/关闭后清空，不写入浏览器存储、文件、URL 或日志。没有「记住 Key」，非敏感的减少动态效果偏好可保存。
不要把 Key 或个人敏感资料写进提问。情绪台词不能当作物证。
开发验证没有使用真实账户 Key，因此真实在线鉴权、计费和生成还需你在设置中测试。

六、操作与暂停
鼠标或触屏选择；键盘 Tab 切换按钮，Enter 确认。
案卷内容可滚动阅读。ESC 关闭弹窗或暂停；F11 使用浏览器全屏。
切到其他标签页/窗口后会自动暂停，回来请点「继续本案」。暂停会保留当前阅读位置和已输入的问题。
「减少动态效果」可关闭人物动画并立即显示文字。
刷新会重新开始，当前没有对局存档。

七、常见问题
页面空白或资源缺失：完整解压并保留「web」里的全部文件，使用较新 Chrome/Edge。
需要中文输入：直接点击提问框，使用系统输入法或粘贴。
AI 连接失败：检查 Key、网络、余额及模型权限；使用有 Python 的一键启动。关闭在线仍可游玩。
一键启动后地址是 127.0.0.1：这是本机服务，不是公网地址，不需要部署。
关闭页面后本地服务约 30 分钟无活动自动退出。若需要立刻关闭，可在任务管理器查看命令行包含本项目 scripts/server.py 的 Python 进程。
没有互联网/局域网双人模式，仍是同一台设备交接。请双方约定不打开开发者工具查看本地数据。

八、源码位置
web：HTML、CSS、JavaScript、图片和字体，生产页面不依赖 npm。
scripts：本地服务与 Windows 启动辅助。
tests：规则、接口、安全边界和浏览器流程测试。
docs：验证记录及创作参考。
详细开发方法见「README.md」。
